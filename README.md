# Dabba Party Fam Jam

A polished, host-controlled family game-show application designed for a large TV or projector.

## Games

- Chain Reaction
- Price Challenge

## Features

- Practice rounds
- Host controls and audience display
- Editable teams and content
- Fullscreen mode
- Persistent scoring
- Configurable timers and rounds
- Independent hidden-total carts
- Undo and guarded resets

## Local Setup

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Keyboard controls: Space starts or pauses, Enter marks correct, X marks wrong, R reveals, and arrow keys navigate.
